- Ubuntu 版本：Ubuntu 22.04.5 LTS（VERSION_ID=22.04）
- 使用的 Agent 工具：豆包（AI 助手），协助规划环境方案、诊断报错、下载并校验安装包、整理命令练习步骤

## 心得体会

这是我第一次接触 Ubuntu 和命令行，一开始连终端、目录、路径都分不清。在 Agent 帮助下，我先理清要交哪些东西，再一步步把环境搭起来。过程中遇到两个问题：一是最初的 PowerShell 不是管理员身份，报"请求的操作需要提升"，Agent 判断是窗口权限不够，需要右键以管理员身份运行；二是官方在线安装卡在 12.5% 不再前进，Agent 检查后台进程后判断是下载源停滞，改为离线下载 WSL 安装包和 Ubuntu 22.04 镜像并校验完整性，最后成功导入并验证版本。

命令练习时，我在专用目录里依次试了目录定位、文件操作和文本查看三组命令：`pwd`、`ls`、`cd` 确认所在目录；`mkdir`、`touch`、`cp`、`mv`、`rm` 新建、复制、移动和删除文件；`cat`、`head`、`tail` 查看内容。练习时我先看清当前目录再操作，删除只针对自己刚建的练习文件。方案、排错和命令解释由 Agent 提供建议，是否执行和最终检查确认都由我自己完成，并对照终端输出核对。

这次实践让我对终端基本操作有了直观认识，也体会到 Agent 适合查资料、给方案和排错，但关键判断和最终提交仍要自己负责。
